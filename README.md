### 🚀 Projects I'm proud of

**[AI Resume Analyser](https://github.com/prishalala/resume-analyser)**
Upload a resume, get back a scored breakdown — ATS fit, skills, grammar, keywords — in under 10 seconds. Flask API on the backend, Anthropic API doing the actual reading.

**RAG Chatbot**
A chatbot that only talks about *your* documents. Feed it PDFs or URLs, it chunks and embeds them, then retrieves the right context before Claude answers — no hallucinated sources.
